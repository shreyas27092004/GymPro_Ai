# Class Booking & Cancellation Policy

Members may book scheduled fitness classes up to 7 days in advance. To ensure fair access to studio capacity, strict cancellation windows apply.

## Rules
- Early Cancellation: Cancellations made at least 2 hours before class start time incur no penalty. The class credit is returned to the member account immediately.
- Late Cancellation: Cancellations within 2 hours of class start time forfeit the class credit.
- No-Show: Failing to check in within 5 minutes of class start results in a no-show mark. Three no-shows within 30 days temporarily restrict booking privileges for 7 days.
